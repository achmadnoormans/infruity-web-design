Variasi Desain Popup Hapus

5 Pilihan desain modal konfirmasi untuk aksi destruktif (Hapus Target).

Opsi 1: Modern Minimalist

Hapus Target Cabang?

Target untuk cabang Gresik / Sidokumpul pada periode ini akan dihapus secara permanen. Tindakan ini tidak dapat dibatalkan.

Opsi 2: Centered Focus

Konfirmasi Penghapusan

Anda yakin ingin menghapus target ini? Data yang terhapus tidak akan masuk ke dalam laporan performa ERP.

Opsi 3: Elegant Glass

Hapus Data Target

Cabang Sidokumpul

⚠️ Peringatan: Data yang dihapus tidak bisa direstorasi melalui sistem. Anda harus membuat ulang secara manual jika diperlukan.

Opsi 4: Type to Confirm

Penghapusan Bersyarat

Ketik HAPUS di bawah ini untuk mengonfirmasi bahwa Anda sadar akan konsekuensi penghapusan target cabang ini.

Opsi 5: Floating Bottom Card

Hapus "Gresik / Sidokumpul"?

Target yang dihapus tidak akan ditampilkan lagi. Yakin ingin melanjutkan?
